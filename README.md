# Minecraft: The Other Update

Minecraft: The Other Update is an unofficial alternative continuation of Minecraft Java Edition, built from Release 1.0.0.

The project develops the game as if its update history followed a different path, adding original features and overhauling existing systems while preserving the character of early Release Minecraft.

## Current status

The project is in early development.

A working Minecraft 1.0.0 development environment has been established with RetroMCP-Java and Java 8. The client recompiles and launches successfully, and the main-menu version text has been changed to identify development builds.

There is no public playable release yet.

## First feature

The first planned gameplay feature is a Minecraft 1.0 adaptation of [Beds, but Endgame](https://github.com/passziff/beds-but-endgame).

The initial design includes:

- A Bedside Table required for sleeping
- Respawn-point setting even when sleeping is denied
- A new Glowstone Lantern
- Nightmares when sleeping without a protected bedside setup

The exact recipes, balance and presentation may change during development.

## Development

Development uses RetroMCP-Java with Minecraft Java Edition 1.0.0 and Java 8.

This repository contains only original project files, documentation, assets and source patches. It does not contain Minecraft source code, Minecraft assets or a Minecraft JAR.

See [docs/development.md](docs/development.md) for the local workflow.

## Installation

No public build is available yet.

Future releases are planned as isolated launcher instances for Prism Launcher and compatible launchers.

## Testing status

The unmodified Minecraft 1.0.0 client and the first title-screen change have been tested in singleplayer.

Multiplayer and the dedicated server have not been tested.
